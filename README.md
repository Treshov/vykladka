# Выкладка — трекер роликов

Личный трекер регулярности публикаций по нескольким каналам. Календарь на
каждый канал, отметки «выложил / не выложил / выходной / запланировано»,
серии (streak), тёмная тема, демо-режим для скриншотов, экспорт/импорт
бэкапа в JSON.

Чистый HTML/CSS/JS без сборки и зависимостей. Все данные хранятся в
`localStorage` браузера — сервер не нужен, бэкенда нет.

## Запуск локально

ES-модули не грузятся напрямую с `file://` (это ограничение браузера, а не
приложения) — нужен любой локальный HTTP-сервер. Подойдёт что угодно:

```bash
# если есть Python
python3 -m http.server 5173

# если есть Ruby (есть в macOS "из коробки")
ruby -run -e httpd . -p 5173

# если есть Node
npx serve .
```

Затем открыть http://localhost:5173.

Проще всего — расширение "Live Server" в VS Code (клик правой кнопкой на
`index.html` → Open with Live Server).

## Деплой

Статика — можно выложить как есть на GitHub Pages, Netlify, Vercel и т.п.
Для GitHub Pages: запушить репозиторий и включить Pages в настройках
(Settings → Pages → Deploy from branch).

## Структура

```
index.html          разметка + все модалки/поповер
css/styles.css       стили, светлая/тёмная тема через CSS-переменные
js/
  storage.js         чтение/запись localStorage, экспорт/импорт бэкапа
  dateUtils.js        работа с датами
  stats.js           серии (streak) и месячная статистика
  render.js           построение DOM из состояния
  main.js             состояние, обработчики событий, точка входа
```

## Формат данных

```json
{
  "channels": [
    { "id": "...", "name": "...", "avatar": "data:image/jpeg;base64,...", "accent": "#ff5f6d,#ffc371", "start": "2026-09-19" }
  ],
  "marks": {
    "<channelId>": { "2026-09-19": "done" }
  }
}
```

Статусы отметки: `done`, `missed`, `off`, `planned`.
